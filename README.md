# AGI for Anyone — Homebrew tap

A native macOS app for Claude Code. [Source](https://github.com/agiforanyone/app) · MIT.

```sh
brew install --cask agiforanyone/tap/agi-for-anyone
```

Installs the signed, notarized build straight from the
[releases page](https://github.com/agiforanyone/app/releases/latest) —
no Gatekeeper warning, nothing to compile.

To update: `brew upgrade --cask agi-for-anyone`
